# 명령어 모음

강의에서 쓰는 명령을 한곳에 모았습니다.

## 터미널에서 쓰는 명령 (클로드 코드 밖)

| 명령 | 하는 일 |
|---|---|
| `irm https://claude.ai/install.ps1 \| iex` | 클로드 코드 설치 (Windows 파워셸) |
| `curl -fsSL https://claude.ai/install.sh \| bash` | 클로드 코드 설치 (macOS, Linux) |
| `claude` | 지금 폴더에서 클로드 코드 실행 |
| `claude --version` | 설치된 버전 확인 |
| `claude --continue` | 이 폴더의 가장 최근 대화 이어서 하기 |
| `claude --resume` | 이전 대화 목록에서 골라 이어서 하기 |
| `claude update` | 최신 버전으로 업데이트 |
| `claude doctor` | 설치 상태 진단 |
| `claude mcp add --transport http notion https://mcp.notion.com/mcp` | 노션 MCP 서버 등록 |
| `npx vibeindex add vibeindex/skills --skill vibeindex` | 바이브 인덱스 스킬 설치 (Node.js 필요) |

## 클로드 코드 안에서 쓰는 명령

**정보 확인**

| 명령 | 하는 일 |
|---|---|
| `/help` | 명령어 목록 |
| `/status` | 모델·계정 상태 |
| `/context` | 지금 컨텍스트(토큰)가 얼마나 찼는지 |
| `/usage` | 요금제 사용 한도 |

**세션 관리**

| 명령 | 하는 일 |
|---|---|
| `/clear` | 대화 초기화 |
| `/compact` | 대화 압축. 뒤에 남길 내용을 적을 수 있음 (예: `/compact 검증 규칙 위주로`) |
| `/rewind` | 이전 시점으로 되돌리기 (`Esc` 두 번과 같음) |
| `/resume` | 이전 대화 불러오기 |

**설정·도구**

| 명령 | 하는 일 |
|---|---|
| `/init` | 프로젝트를 분석해 CLAUDE.md 만들기 |
| `/memory` | CLAUDE.md 열어서 편집, 자동 메모리 켜고 끄기 |
| `/model` | 모델 바꾸기 |
| `/config` | 설정 화면 (Dynamic workflows 켜기 등) |
| `/doctor` | 상태 진단 |
| `/mcp` | 연결된 MCP 서버 확인과 인증 |
| `/plugin` | 플러그인·마켓플레이스 관리 |
| `/plugin marketplace add anthropics/skills` | 앤트로픽 공식 스킬 마켓플레이스 추가 |
| `/deep-research 질문` | 여러 출처를 교차 검증하는 조사 보고서 |
| `/workflows` | 실행 중인 워크플로(딥 리서치 등) 진행 상황 |

**키보드**

| 키 | 하는 일 |
|---|---|
| `Esc` | 클로드가 하던 일 멈추기 |
| `Esc` 두 번 | 이전 시점으로 되돌리기 |
| `Shift + Tab` | 권한 모드 바꾸기 (터미널) |
| `@파일이름` | 특정 파일을 대화에 불러오기 |

## 내가 만드는 명령

| 위치 | 실행 |
|---|---|
| `.claude/commands/이름.md` | `/이름` (예전 방식, 계속 작동) |
| `.claude/skills/이름/SKILL.md` | `/이름` (새 방식, 권장) |
| `.claude/agents/이름.md` | "이름에게 ~를 시켜 줘" (서브 에이전트) |

명령 안에서 `$ARGUMENTS`는 명령 뒤에 붙인 내용 전체, `$1`, `$2`는 첫째·둘째 값을 뜻합니다.
