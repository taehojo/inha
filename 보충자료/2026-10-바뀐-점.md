# 2026년 10월 기준 바뀐 점

책 『혼자 공부하는 바이브 코딩 with 클로드 코드』나 이전 강의 자료와 달라진 내용입니다. 이 저장소의 프롬프트와 안내는 모두 아래 변경을 반영했습니다.

| 항목 | 이전 | 지금 (2026년 10월) |
|---|---|---|
| Windows 설치 | Git for Windows를 먼저 설치해야 함 | Git은 선택 사항. 없으면 파워셸로 실행됨 |
| 아티팩트 시작 화면 | [새 아티팩트] → [처음부터 시작하기], 완성 후 [게시] | 사이드바 [아티팩트] → Make something new에서 카드 선택(예: Dashboard), 완성 후 [공유] |
| 서브 에이전트 만들기 | `/agents` → Create new agent 화면 | 2.1.198부터 `/agents`가 없어짐. 말로 설명하면 클로드 코드가 정의 파일을 만듦 |
| 커스텀 명령어 | `.claude/commands/이름.md` | 스킬과 통합. `.claude/skills/이름/SKILL.md`도 `/이름`으로 실행되며 새로 만들 때 권장. 기존 commands 방식도 계속 작동 |
| 데스크톱 앱 | 이전 대화 이어가기, 권한 우회, 장시간 실행이 안 됨 | 모두 됨(사이드바·`/resume`, 권한 우회·자동 모드, 클라우드 세션·예약 작업). 헤드리스 실행, 파이프 조합, 에이전트 팀은 여전히 CLI 전용 |
| 오픈라우터 무료 모델 | `deepseek/deepseek-chat-v3.1:free`, `google/gemma-3-27b-it:free` | 무료 제공 종료. 예: `google/gemma-4-31b-it:free`(이미지·텍스트 모두 가능) |
| 조사 기능 | (없음) | `/deep-research` 내장 워크플로. Pro는 `/config`에서 Dynamic workflows를 켜야 함 |

무료 모델 목록과 클로드 코드 화면은 앞으로도 바뀔 수 있습니다. 실습이 안 되면 [문제 해결 FAQ](문제해결-FAQ.md)를 먼저 보세요.
