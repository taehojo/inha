# 문제 해결 FAQ

실습 중에 자주 막히는 곳을 모았습니다. 여기에 없는 문제는 오류 메시지를 그대로 클로드 코드에 붙여 넣고 "이 오류를 해결해 줘"라고 요청해 보세요. 대부분 스스로 고칩니다.

## 설치와 실행

**Q. 설치했는데 `claude`를 입력하면 "인식되지 않습니다"라고 나와요.**
설치가 끝난 뒤 터미널(파워셸) 창을 **닫고 새로 열어야** 합니다. 새 창에서도 안 되면 `claude doctor`를 실행해 보거나, 설치 명령을 한 번 더 실행하세요.

**Q. `'irm' is not recognized` 오류가 나요.**
명령 프롬프트(CMD)에 파워셸 명령을 넣은 경우입니다. 작업 표시줄 검색창에서 `powershell`을 찾아 실행한 뒤 다시 입력하세요. CMD를 계속 쓰려면 [00-시작하기](../00-시작하기/README.md)의 CMD용 설치 명령을 쓰세요.

**Q. 로그인했는데 클로드 코드를 쓸 수 없다고 나와요.**
클로드 코드는 Pro 이상 요금제(Pro, Max, Team, Enterprise)나 Console(API) 계정이 필요합니다. 무료 요금제로는 쓸 수 없습니다. 아티팩트(1차시 ②)는 무료 계정으로도 됩니다.

**Q. Git을 꼭 설치해야 하나요?**
Windows에서는 선택 사항입니다. 깃이 있으면 클로드 코드가 Bash로, 없으면 파워셸로 명령을 실행합니다. 강의 화면과 똑같이 하려면 설치를 권장합니다.

**Q. 클로드 코드가 엉뚱한 폴더의 파일을 건드려요.**
클로드 코드는 실행한 폴더를 프로젝트로 봅니다. 실습 폴더에서 마우스 오른쪽 버튼 → [터미널에서 열기]로 연 다음 `claude`를 실행하세요.

**Q. 강의 화면과 메뉴가 달라요.**
클로드 코드와 클로드 웹은 자주 업데이트됩니다. 바뀐 점은 [2026-10-바뀐-점](2026-10-바뀐-점.md)을 확인하세요.

## 아티팩트

**Q. [새 아티팩트] 버튼이나 [처음부터 시작하기]가 안 보여요.**
2026년 10월에 화면이 바뀌었습니다. 왼쪽 사이드바 [아티팩트] → "Make something new"에서 [Dashboard]를 고르고 프롬프트를 입력하세요. 공유는 오른쪽 위 [공유] 버튼으로 합니다.

## API와 오픈라우터

**Q. API 테스트에서 401 오류가 나요.**
키가 틀렸거나 `.env`를 읽지 못한 경우입니다. `.env` 파일이 실습 폴더 안에 있는지, 내용이 `OPENROUTER_API_KEY=키` 형식인지(따옴표나 공백 없이) 확인하세요.

**Q. 모델을 찾을 수 없다(404)고 나와요.**
무료 모델은 자주 생기고 없어집니다. [openrouter.ai/models](https://openrouter.ai/models)에서 "free"로 검색해 지금 있는 모델 이름으로 바꾸세요. 이미지 인식에는 이미지 입력을 지원하는 모델을 골라야 합니다.

**Q. 429 오류(요청이 너무 많음)가 나요.**
무료 모델의 사용 한도에 걸린 것입니다. 잠시 기다렸다 다시 하거나 다른 무료 모델로 바꾸세요.

**Q. `.env` 파일이 탐색기에서 안 보여요.**
점(.)으로 시작하는 파일은 숨김 파일입니다. Windows 탐색기 [보기] → [표시] → [숨긴 항목]을 켜세요.

**Q. 실수로 API 키를 채팅이나 깃허브에 올렸어요.**
바로 오픈라우터의 Keys 메뉴에서 그 키를 삭제하고 새 키를 만드세요. 삭제하면 올라간 키는 쓸 수 없게 됩니다.

## 에이전트, MCP, 스킬

**Q. 책에 나오는 `/agents` 명령이 없어요.**
클로드 코드 2.1.198부터 없어졌습니다. "서브 에이전트 code-bug-analyzer를 만들어 줘..."처럼 말로 설명하면 클로드 코드가 정의 파일을 만들어 줍니다. [3차시 ①](../3차시-심화/README.md#1-실습-07-서브-에이전트의-개념과-코드-리뷰-에이전트)을 보세요.

**Q. 노션 MCP를 등록했는데 작동하지 않아요.**
클로드 코드 안에서 `/mcp`를 입력하고 notion을 골라 브라우저 인증을 마쳐야 합니다. 노션에서 클로드가 접근할 페이지 권한도 허용해야 합니다.

**Q. `npx` 명령이 인식되지 않아요.**
Node.js가 없어서입니다. [nodejs.org](https://nodejs.org)에서 LTS 버전을 설치하고 터미널을 새로 여세요.

**Q. `/deep-research`가 없거나 실행되지 않아요.**
Pro 요금제는 `/config`에서 Dynamic workflows를 먼저 켜야 합니다. 웹 검색 기능이 필요하므로 회사·기관 정책으로 막혀 있으면 실행되지 않을 수 있습니다.

## 긴 대화

**Q. 대화가 길어지니 클로드가 처음 지시를 잊어요.**
컨텍스트가 꽉 찬 것입니다. `/context`로 확인하고, 중요한 내용을 .md 파일로 남기게 한 뒤 `/clear`로 새로 시작하세요. [2차시 ④](../2차시-기본/README.md#4-컨텍스트-관리-긴-대화에서-품질-유지하기)에 6가지 방법이 있습니다.

**Q. 클로드가 잘못 고쳐서 망가졌어요.**
`Esc`를 두 번 누르거나 `/rewind`로 문제가 생기기 전 시점으로 되돌리세요.
