# 교수자를 위한 활용 가이드

강의에서 배운 기능을 수업과 연구에 쓰는 방법을 차시별로 모았습니다. 마지막의 "책임 있는 활용 점검표"는 실제 수업에 쓰기 전에 꼭 확인해 주세요.

## 1차시에서 배운 것으로

| 활용 | 방법 | 예시 프롬프트 |
|---|---|---|
| 수업 안내 페이지 | 아티팩트로 강의 일정표·과제 안내 페이지를 만들고 링크로 공유 | "15주 강의 일정과 과제 마감일을 한눈에 보여 주는 안내 페이지를 만들어 줘" |
| 복습 퀴즈 | PRD 한 장으로 단원별 퀴즈 게임을 만들어 수업 마무리에 활용 | "세포 생물학 3단원 복습용 4지선다 퀴즈 게임의 PRD를 작성해 줘" |
| 연구 데이터 분석 | 분석·시각화 코드를 자연어로 요청하고 결과를 직접 확인 | "이 CSV 파일에서 집단별 평균을 비교하는 그래프를 그려 줘" |
| 교수자의 검증 | AI가 만든 문항·정답·코드는 직접 확인하고, 학생 개인정보는 넣지 않기 | |

## 2차시에서 배운 것으로

| 활용 | 방법 |
|---|---|
| 출제 기준 문서화 | CLAUDE.md에 문항 작성 원칙과 채점 기준을 적어 두고 매 학기 재사용 |
| 반복 업무 명령어화 | 문항 점검·공지문 작성처럼 자주 하는 일을 커스텀 명령어로 저장 (예: `/notice` 공지문 초안, `/quiz-validate` 문항 점검) |
| AI 기능을 붙인 도구 | API로 실험 사진 관찰 기록, 글쓰기 초안 피드백 같은 수업 도구 제작 |
| 키와 데이터 관리 | API 키는 .env에만 두고 공유 금지, 성적·학생 정보는 외부 API로 보내지 않기 |

## 3차시에서 배운 것으로

| 활용 | 방법 |
|---|---|
| 읽기 자료 준비 | 논문·강의 PDF 요약 앱과 딥 리서치로 자료를 조사하고 출처는 직접 확인 |
| 수업 자료 관리 | MCP로 노션 등에 강의 노트와 공지를 정리하고 공유 |
| 형식 통일 | 스킬·플러그인으로 강의 슬라이드와 문서를 같은 형식으로 생성 |
| 사람 승인 단계 | 성적 처리·공지 발송처럼 되돌리기 어려운 작업은 마지막에 사람이 확인 |

## 책임 있는 활용 점검표

수업이나 연구에 AI가 만든 결과물을 쓰기 전에 확인하세요.

- [ ] **정확성**: 퀴즈 정답, 요약문의 사실, 인용한 출처를 직접 확인했는가?
- [ ] **개인정보**: 학생 이름, 학번, 성적, 연락처를 AI 채팅이나 외부 API에 넣지 않았는가?
- [ ] **저작권**: 교재·논문 전문을 무단으로 올리거나, 저작권이 있는 이미지를 그대로 쓰지 않았는가?
- [ ] **접근성**: 만든 도구를 휴대폰에서도 쓸 수 있고, 글자 크기와 색 대비가 충분한가?
- [ ] **키 관리**: API 키가 코드, 슬라이드, 깃허브, 공유 링크에 들어가 있지 않은가?
- [ ] **비용**: 오픈라우터 키에 사용 한도를 정해 두었는가?
- [ ] **되돌릴 수 없는 작업**: 성적 입력, 메일 발송, 파일 삭제 같은 작업 앞에 사람이 확인하는 단계를 두었는가?
- [ ] **학생 안내**: 수업 도구에 AI가 쓰였다는 사실과 그 한계를 학생에게 알렸는가?

AI는 초안을 빠르게 만드는 도구이고, 교육적 판단과 최종 책임은 교수자에게 있습니다.
