퀴즈 문제(questions.js)를 검증해 줘.

- $ARGUMENTS에 카테고리(한국사, 과학, 세계지리, 예술과 문화 중 하나)가 들어오면 그 카테고리의 문제만, 비어 있으면 전체 문제를 검증해.
- '가장', '최초', '최대', '최소' 같은 최상급 표현이 들어간 문제를 찾아 목록으로 보여 줘.
- 각 문제마다 어떤 기준(면적, 인구, 연도 등)을 명시해야 정답이 하나로 정해지는지 알려 줘.
- CLAUDE.md의 "퀴즈 문제 교차 검증 가이드라인"을 기준으로 판단해.
- 파일은 수정하지 말고, 고칠 문제와 수정안만 보고해.
