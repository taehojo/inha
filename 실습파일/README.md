**상식 퀴즈 게임 쓰는 방법**
1. 저장소 첫 화면에서 [Code] → [Download ZIP]으로 내려받아 압축을 풉니다.
2. `실습파일/상식퀴즈게임` 폴더를 내 실습 폴더로 복사합니다.
3. `index.html`을 브라우저로 열면 게임이 실행됩니다.
4. 그 폴더에서 터미널을 열고 `claude`를 실행해 2차시를 시작합니다.

퀴즈 문제는 `questions.js`에 있습니다. AI가 만든 문제이므로 정답이 틀리거나 기준이 모호한 문제가 섞여 있을 수 있고, 2차시 ②에서 이 문제들을 가이드라인으로 점검합니다.
