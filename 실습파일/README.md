**상식 퀴즈 게임 쓰는 방법**
1. [상식퀴즈게임.zip](https://github.com/taehojo/inha/raw/main/%EC%8B%A4%EC%8A%B5%ED%8C%8C%EC%9D%BC/%EC%83%81%EC%8B%9D%ED%80%B4%EC%A6%88%EA%B2%8C%EC%9E%84.zip)을 누르면 파일 하나로 내려받아집니다.
2. 압축을 풀면 `상식퀴즈게임` 폴더가 생깁니다. Windows는 마우스 오른쪽 버튼 → [모두 압축 풀기], macOS는 더블클릭입니다. 이 폴더를 내 실습 폴더로 옮겨 둡니다.
3. `index.html`을 브라우저로 열면 게임이 실행됩니다.
4. 그 폴더에서 터미널을 열고 `claude`를 실행해 2차시를 시작합니다.

퀴즈 문제는 `questions.js`에 있습니다. 세계지리 첫 문제 "세계에서 가장 긴 강은?"은 측정 기준에 따라 아마존강도 나일강도 답이 될 수 있는, 일부러 남겨 둔 모호한 문제입니다. 2차시 ②에서 CLAUDE.md 가이드라인으로 이런 문제를 찾아 고칩니다.
