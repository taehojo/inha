# 클로드 코드를 활용한 바이브 코딩

인하대학교 교수학습개발센터 2026학년도 온라인 교수법 콘텐츠 「클로드 코드를 활용한 바이브 코딩」의 실습 자료실입니다.
강의 영상에 나오는 프롬프트, 실습 파일, 보충 자료를 모두 이곳에 모았습니다. 영상을 보면서 이 페이지를 옆에 띄워 두고, 프롬프트를 복사해 그대로 따라 하시면 됩니다.

- 강사: 조태호 (인디애나대학교 의과대학 영상의학/영상과학과)
- 대상: 프로그래밍 경험이 없거나 적은 교수자 (전공 무관)
- 구성: 3개 차시 (기초다지기 · 기본 · 심화)

## 처음 오셨다면

1. **[00-시작하기](00-시작하기/)** 에서 준비물(클로드 요금제, 계정)과 설치 방법을 먼저 확인하세요.
2. 차시 영상을 보면서 아래 표의 차시 폴더를 열고, 영상에 나오는 프롬프트를 복사해 붙여 넣으세요.
3. 막히는 곳이 있으면 **[문제 해결 FAQ](보충자료/문제해결-FAQ.md)** 를 먼저 찾아보세요.

> **실습 파일 바로 받기:** [상식퀴즈게임.zip](https://github.com/taehojo/inha/raw/main/%EC%8B%A4%EC%8A%B5%ED%8C%8C%EC%9D%BC/%EC%83%81%EC%8B%9D%ED%80%B4%EC%A6%88%EA%B2%8C%EC%9E%84.zip) (2차시 CLAUDE.md 실습용 퀴즈 게임, 누르면 파일 하나로 내려받아집니다)
>
> 저장소 전체가 필요하면 위쪽의 초록색 **[Code]** 버튼 → **[Download ZIP]** 을 누르세요.

## 차시별 자료

| 차시 | 주제 | 학습 목표 | 자료 |
|---|---|---|---|
| 1차시 기초다지기 | 바이브 코딩 이해와 클로드 코드 첫 실행 | 바이브 코딩을 이해하고 첫 프로그램을 완성한다 | [1차시 바로가기](1차시-기초다지기/) |
| 2차시 기본 | 프로젝트 관리와 AI 연동 앱 만들기 | 규칙과 명령어로 작업을 관리하고 AI 앱을 만든다 | [2차시 바로가기](2차시-기본/) |
| 3차시 심화 | AI 에이전트와 바이브 코딩의 확장 | 에이전트·MCP·스킬로 기능을 넓히고 검증한다 | [3차시 바로가기](3차시-심화/) |

## 차시별 목차

**1차시 기초다지기**
1. 바이브 코딩의 등장 배경과 연구 현장 활용 사례
2. 클로드 아티팩트로 만드는 첫 웹페이지
3. 클로드 코드 설치와 첫 실행
4. [실습] 손글씨 숫자 인식 프로그램 만들기
5. 꼭 알아야 할 기본 명령어
6. 5W1H와 PRD로 요구사항 정리하기
7. [실습] PRD로 상식 퀴즈 게임 만들기

**2차시 기본**
1. CLAUDE.md와 /init으로 프로젝트 규칙 정하기
2. /memory로 퀴즈 문항 검증 기준 추가하기
3. 커스텀 명령어로 반복 작업 자동화하기
4. 컨텍스트 관리: 긴 대화에서 품질 유지하기
5. API 키 발급과 .env로 안전하게 연결하기
6. [실습] 사진 속 재료로 레시피 추천 앱 만들기

**3차시 심화**
1. 서브 에이전트의 개념과 코드 리뷰 에이전트
2. [실습] AI 개발팀 에이전트로 PDF 요약 웹앱 만들기
3. MCP로 노션 등 외부 서비스 연결하기
4. 스킬·플러그인으로 기능 확장하기 (PPT 생성)
5. /deep-research로 조사·검증 루프 설계하기
6. 하네스 설계: 검증 기준과 사람 승인 단계 넣기

## 꼭 지켜 주세요

- **API 키는 어디에도 올리지 마세요.** 이 저장소, 깃허브, 채팅, 슬라이드에 키를 붙여 넣으면 안 됩니다. 자세한 방법은 [2차시 ⑤](2차시-기본/README.md#5-api-키-발급과-env로-안전하게-연결하기)에 있습니다.
- **학생 개인정보와 성적은 AI에 넣지 마세요.** 실습은 예시 데이터로 충분합니다.
- **AI가 만든 결과는 직접 확인하세요.** 퀴즈 정답, 요약문, 코드 모두 마지막 판단은 교수자의 몫입니다.
