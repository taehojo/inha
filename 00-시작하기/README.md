# 00. 시작하기

강의를 따라 하기 전에 필요한 준비물과 설치 방법입니다. 1차시 영상의 "실습 준비편"과 같은 내용입니다.

## 준비물

| 준비물 | 언제 필요한가 | 비고 |
|---|---|---|
| PC와 인터넷 | 전체 | Windows 10(1809 이상), macOS 13 이상, Ubuntu 20.04 이상 |
| 클로드 계정 | 1차시 ② 아티팩트부터 | 아티팩트는 무료 계정으로도 할 수 있습니다 |
| 클로드 **Pro 이상** 요금제 | 1차시 ③ 클로드 코드부터 | 클로드 코드는 Pro, Max, Team, Enterprise 요금제나 Console(API) 계정이 있어야 합니다. **무료 요금제로는 클로드 코드를 쓸 수 없습니다.** |
| 오픈라우터(OpenRouter) 계정 | 2차시 ⑤부터 | 무료 가입, 무료 모델로 실습 가능 |
| 노션(Notion) 계정 | 3차시 ③ MCP | 무료 계정으로 충분합니다 |
| Node.js | 3차시 ④ 스킬 설치 | `npx` 명령을 쓰기 위해 필요합니다. [nodejs.org](https://nodejs.org)에서 LTS 버전 설치 |

## 실습 폴더 만들기

바탕화면 등에 실습용 폴더를 하나 만들고, 실습마다 하위 폴더를 따로 만드는 것을 권장합니다. 프로젝트가 섞이지 않아 클로드 코드가 헷갈리지 않습니다.

```
inha-vibecoding/
├── 실습01-손글씨인식/
├── 실습03-퀴즈게임/
├── 실습06-레시피앱/
└── 실습08-PDF요약/
```

## 클로드 코드 설치 (Windows)

1. **Git for Windows 설치 (권장, 선택 사항)**
   [git-scm.com](https://git-scm.com)에서 Git for Windows를 내려받아 설치합니다.
   설치하면 클로드 코드가 Bash로 명령을 실행하고, 설치하지 않으면 파워셸(PowerShell)로 실행합니다. 둘 다 동작하지만, 강의 화면과 같게 하려면 설치를 권장합니다.
2. 작업 표시줄 검색창에 `powershell`을 입력하고 Enter를 누릅니다. 관리자 권한은 필요 없습니다.
3. 파워셸에 아래 명령을 붙여 넣고 Enter를 누릅니다. 설치 중에는 진행 표시가 없으니 잠시 기다리세요.

   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```

4. 설치가 끝나면 **파워셸 창을 닫고 새로 연 다음** 아래 명령으로 확인합니다. 버전 번호가 나오면 성공입니다.

   ```powershell
   claude --version
   ```

5. `claude`를 입력하면 클로드 코드가 실행됩니다. 처음 실행하면 브라우저가 열리며 로그인을 요청합니다.

> 명령 프롬프트(CMD)를 쓰는 경우에는 아래 명령으로 설치합니다.
> ```
> curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
> ```

## 클로드 코드 설치 (macOS / Linux)

1. `Command + Space`로 Spotlight를 열고 "터미널"을 실행합니다.
2. 깃이 설치되어 있는지 확인합니다. 버전이 나오지 않으면 안내에 따라 설치합니다.

   ```bash
   git --version
   ```

3. 아래 명령으로 클로드 코드를 설치합니다.

   ```bash
   curl -fsSL https://claude.ai/install.sh | bash
   ```

4. 설치 완료 안내가 나오면 터미널을 닫았다가 다시 열고, `claude --version`으로 확인한 뒤 `claude`로 실행합니다.

## 작업 폴더에서 클로드 코드 실행하기

클로드 코드는 **실행한 폴더**를 프로젝트로 인식합니다. 꼭 실습 폴더에서 실행하세요.

- Windows: 실습 폴더에서 마우스 오른쪽 버튼 → **[터미널에서 열기]** → `claude` 입력
- macOS: 터미널에 `cd `(cd 다음에 한 칸 띄우기)를 입력하고, Finder에서 실습 폴더를 터미널 창으로 끌어다 놓은 뒤 Enter → `claude` 입력

## 클로드 데스크톱 앱

터미널이 낯설다면 데스크톱 앱의 **Code** 탭에서도 클로드 코드를 쓸 수 있습니다. [claude.com/download](https://claude.com/download)에서 내려받습니다.

| 데스크톱 앱에서 되는 것 | 데스크톱 앱에서 안 되는 것 |
|---|---|
| 이전 대화 이어가기 (사이드바, `/resume`) | 헤드리스 실행(`--print`), 스크립트 자동화 |
| 권한 우회·자동 모드 | 파이프로 다른 명령과 조합하기 |
| 클라우드 세션, 예약 작업 | 에이전트 팀 |
| 파일·이미지 첨부, 플러그인 관리 화면 | 일부 터미널 전용 명령(`/permissions` 등) |

2026년 10월 기준입니다. 강의는 주로 터미널(CLI)로 진행합니다. 지도를 읽을 줄 알면 내비게이션도 쓸 수 있지만, 내비게이션만 써 본 사람은 지도를 읽기 어렵기 때문입니다.

## 오픈라우터 API 키 준비 (2차시 전까지)

2차시 ⑤부터는 AI 모델을 내 프로그램에서 부르기 위해 API 키가 필요합니다. 강의에서는 여러 AI 모델을 키 하나로 쓸 수 있는 [오픈라우터](https://openrouter.ai)를 사용합니다.

1. [openrouter.ai](https://openrouter.ai)에 가입하고 로그인합니다.
2. 계정 메뉴의 **Keys**에서 새 API 키를 만듭니다.
3. 키는 만들 때 한 번만 보입니다. 바로 복사해 두세요.
4. 키별 사용 한도(credit limit)를 정해 두면 실수로 큰 비용이 나가는 것을 막을 수 있습니다.
5. 이름 끝에 `:free`가 붙은 모델은 무료입니다. [openrouter.ai/models](https://openrouter.ai/models)에서 "free"로 검색해 확인하세요.

키를 어디에 어떻게 저장하는지는 [2차시 ⑤](../2차시-기본/README.md#5-api-키-발급과-env로-안전하게-연결하기)에서 다룹니다.
